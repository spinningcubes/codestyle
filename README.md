# codestyle
Spinningcubes code style

To get it with cmake

```cmake
# Get Spinningcubes CodeStyle
file(DOWNLOAD "https://raw.githubusercontent.com/spinningcubes/codestyle/refs/heads/main/.clang-format" ${CMAKE_SOURCE_DIR}/.clang-format)
file(DOWNLOAD "https://raw.githubusercontent.com/spinningcubes/codestyle/refs/heads/main/.editorconfig" ${CMAKE_SOURCE_DIR}/.editorconfig)
```
